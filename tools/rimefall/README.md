# Rimefall candidates (tools/rimefall)

Makes the candidate looks for Rimefall: frozen models of the Ice Necromancer's possible servants (bosses) and of
Rimefall's possible regular mobs. The user asked for **the looks only**: no animations, sounds or fight. They stand in a
gallery in the game (`/dross showcase boss_designs rimefall`) so the user can pick.

What's built now (October 18, 2026) is **the user's picks from round 2**, reworked to their round 3 notes: 11 models
(see the table at the end). What round 3 dropped (the Aurora Eel's ten eye studies, the blue-eyed Fisher, the
full-size Huntsman and the ten riders, round 2's Rimehorn coat and the first layered one) is archived in `rimedesigns/round3/` and `boss-previews/rimefall/round3/`. Round 1's 22 designs are archived in
`rimedesigns/round1/` and round 2's full set of 23 in `rimedesigns/round2/` (their previews in
`boss-previews/rimefall/round1/` and `round2/`); they aren't built any more.

Everything is generated by Python, never drawn by hand, the same way as the Cinder Colossus (`tools/golems`) and the Rat
King (`tools/ratking`); see `BOSS_GUIDE.md`.

## Running it

From the project folder:

```
python tools/rimefall/build.py                    # everything (about 4 minutes)
python tools/rimefall/build.py --only 1 5         # only these designs (every variant): files and previews
python tools/rimefall/build.py --quick <dir> 1 5  # quick previews of these designs into <dir> (nothing in the project)
python tools/rimefall/build.py --previews-only    # previews only; the game files are left alone
python tools/rimefall/closeup.py <out.png> 7B 300 10 5   # a close look at one variant (yaw, elevation, scale)...
python tools/rimefall/zcheck.py 6A                # lists any face pairs that would still flicker
python tools/rimefall/floatcheck.py [6A 7B ...]   # lists any floating pieces (every candidate, or the ones named)
```

Needs Python 3 with numpy and Pillow. It reuses the golem kit (`tools/golems/kit`: GeckoLib's model maths, noise,
lighting). The previews of the Fisher's cabin read Minecraft's own block textures from the game jar in the Gradle cache
(for the pictures only; none is copied into the mod).

## What it writes

| File | What |
|---|---|
| `assets/dross/geo/entity/rimefall/<id>.geo.json` | the model (per-face UVs, see below) |
| `assets/dross/textures/entity/rimefall/<id>.png` | the solid parts |
| `.../<id>_glow.png` | what glows on the solid parts (eyes, a halo, a warm window) |
| `.../<id>_ice.png` | the see-through ice (only for designs that have some) |
| `.../<id>_iceglow.png` | what glows on the ice (the aurora's curtains, glowing cracks) |
| `assets/dross/animations/entity/rimefall/candidate.animation.json` | empty: nothing moves |
| `boss/rimefall/RimefallDesigns.java` | the list the game reads (generated: labels, names, measured sizes, real blocks) |
| `boss-previews/rimefall/<label>_<id>.png` | one variant from four sides, at night and from above |
| `boss-previews/rimefall/all_designs.png` | all of them, three-quarter, bosses then regular mobs |
| `boss-previews/rimefall/lineup.png` | all of them at the same scale, next to a player |

The mod draws the four textures in that order (`boss/rimefall/client/RimefallCandidateRenderer`): solid, glow, ice,
ice glow. The glow comes before the ice so a glowing heart inside a see-through body shines through it. A design's
**real Minecraft blocks** (the Fisher's cabin: `Shape.block(state, corner)`) are listed in `RimefallDesigns` and drawn
by the game itself with its own block models (`client/RimefallBlocksLayer`).

## How it's built

- `rimekit/shapes.py`: every box sits on one root bone at an absolute position and can be turned freely (the models
  never move). Helpers put a box between two points (`seg`), taper chains of them into limbs and horns (`taper`,
  `curve`, `cone`), make round bodies (`blob`, `tube`), flat plates (`plate`), chamfered blocks (`rbox`) and rings
  (`ring`). `Scaled` builds the same design at another size (the Thawed Soldier's 2.5 and 4 blocks). `block()` adds a
  real Minecraft block.
- `rimekit/mats.py`: the materials (fur, layered hanging fur `shag`, skin, scales, shell, ice, northern-lights ice
  `aurora_ice`, glacier, snow, bark, bone, metal, wood, cloth, feathers, eyes, glowing things, the aurora's curtains;
  `eye_disc`, a round eye painted on a flat box with its corners cut away: rim, iris, pupil, glints; ragged `shag`
  and `cloth` cut out their bottom face too, so nothing solid shows under a ragged hem),
  and `tiled`/`tiled_ground`, which paint the mod's own block textures on boxes at one texel a unit, exactly as big as
  on the blocks (the Reaching Hand's fingers wear the Frostbitten Log, its mound is Hoarfrost). Each says whether it's
  opaque (only opaque boxes hide what's inside them).
- `rimekit/uvpack.py`: **per-face UVs**. Every face gets its own rectangle of texture, and faces nobody can see (buried
  in an opaque box, or under the floor) get none and aren't drawn (GeckoLib skips a face with no UV). This keeps the
  giants' textures small (the 27-block hand fits 1024x1024).
- `rimekit/texture.py`: paints the four textures; a texel with alpha between 26 and 249 is see-through ice.
- `rimekit/zfight.py`: finds faces that would flicker (same plane, same way, overlapping), even on turned boxes, and
  grows one box of each pair by a hair (at most 1 unit). Rows of overlapping plates (fur fringes, kilts) need their
  lengths staggered, or the fixer can't separate them all (`zcheck.py` lists what's left).
- `rimekit/connect.py`: **floating pieces** (the user: "make sure for all models that there is no floating" part).
  Boxes that overlap or touch (turned ones too) are joined; any group that touches nothing of the main body is a
  floating piece, and the build warns about it, unless all its materials are in the design's `FREE` tuple (things meant
  to float: the Fisher's broken lake ice, its window light, frozen smoke). A part that grows out of the body (a lock of
  fur, a spine, an antler's tine) is rooted a few units into it.
- `rimekit/blocks.py`: the real blocks in the previews (full cubes, logs, stairs, slabs, panes, doors, lanterns, snow).
- `rimekit/view.py`: the previews, drawn with GeckoLib's maths and Minecraft's entity lighting, see-through ice included.
- `rimedesigns/dNN_<id>.py`: one module per design: `NUMBER`, `ID` (no underscores), `NAME` (at most 15 characters: it
  goes on a sign), `SECTION` (`"boss"` or `"mob"`), `BLURB`, `VARIANTS` (each a dict with its `letter`, its `mood`, the
  sign's third line, at most 15 characters, an optional `note`, and whatever the design reads), `build(s, v)` and
  `materials(v)`. A variant's id is the design's id plus its letter (`reachinghanda`).
